# تطبيق React العربي

هذا مشروع React تم إنشاؤه باستخدام Create React App مع تصميم جميل وحديث باللغة العربية.

## 🚀 المميزات

- **تصميم حديث**: واجهة مستخدم جميلة مع تأثيرات بصرية متقدمة
- **دعم اللغة العربية**: تصميم متوافق مع النصوص العربية (RTL)
- **تصميم متجاوب**: يعمل بشكل مثالي على جميع الأجهزة
- **تأثيرات تفاعلية**: حركات سلسة وتأثيرات hover جميلة

## 📦 التثبيت والتشغيل

### المتطلبات الأساسية
- Node.js (الإصدار 14 أو أحدث)
- npm أو yarn

### خطوات التثبيت

1. **استنساخ المشروع**
```bash
git clone <رابط-المشروع>
cd my-react-app
```

2. **تثبيت التبعيات**
```bash
npm install
```

3. **تشغيل خادم التطوير**
```bash
npm start
```

سيتم فتح التطبيق تلقائياً في المتصفح على العنوان: [http://localhost:3000](http://localhost:3000)

## 🛠️ الأوامر المتاحة

```bash
# تشغيل خادم التطوير
npm start

# بناء المشروع للإنتاج
npm run build

# تشغيل الاختبارات
npm test

# إخراج ملفات البناء
npm run eject
```

## 🎨 التخصيص

### تعديل المحتوى
يمكنك تعديل المحتوى في ملف `src/App.js`:

```jsx
function App() {
  return (
    <div className="App">
      <h1>مرحباً بك في تطبيق React</h1>
      {/* أضف محتوىك هنا */}
    </div>
  );
}
```

### تعديل التصميم
يمكنك تعديل الأنماط في ملف `src/App.css`:

```css
.App {
  background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
  /* أضف أنماطك هنا */
}
```
